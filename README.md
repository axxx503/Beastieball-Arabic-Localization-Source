# Beastieball Arabic Localization

Arabic localization authored from the English version. Version 0.1.5 Beta.
The player package is a single All-in-One installer with embedded translation,
fonts and patch decoder. No separate mod-loader downloads are required.
This repository is the separate **source** package. Upload the player archive
to Nexus Mods; keep this source archive on GitHub.

## Installation

Download the All-in-One player package, extract it, close the game and run its
installer. Select the game folder and install. Choose the Russian language slot
(Русский), then **close and restart the game completely**.
English is preserved. Restart after switching back to English as well.
The installer supports protected upgrades from earlier test versions.
Use the same installer to uninstall and restore the supported originals.
Save files are not installation targets.

## Known issues

The loading screen can show three separated Arabic letters instead of the complete loading phrase. This issue remains unresolved and was explicitly deferred by the user. Do not describe this release as fixing the loading screen.

All currently extracted translation entries are authored or explicitly preserved;
this is not a claim that every image, embedded render path or future game update
has been verified. Editorial and additional visual coverage reviews continue.

## Source contents

Translation JSON, renderer/adapter and installer sources, build and verification
tools, source-hash bindings, original unmodified selected fonts, license notices
and original-dependent patch inputs. Full game files, extracted English tables,
private disassembly dumps and saved games are excluded. Recreate private inputs
from your supported local copy; see BUILDING.md.
